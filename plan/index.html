01 / BACKGROUND & PROBLEM

옷은 골랐는데,
이 자리에 어울릴까?

결혼식, 면접, 첫 출근, 중요한 약속. 옷차림은 취향을 표현하면서 상황에 대한 태도도 전달합니다. 같은 셔츠와 데님도 장소와 시간, 행사 안내에 따라 다르게 받아들여질 수 있습니다.

“내 스타일을 크게 바꾸지 않고,
오늘의 자리에 맞게 입을 수 있을까?”
PROBLEM / 01

기준이 모호한 복장 안내

‘단정하게’, ‘너무 격식 차리지 않게’ 같은 표현은 사람마다 다르게 해석됩니다.

PROBLEM / 02

추천과 내 선택 사이의 거리

새 옷 추천은 많지만, 이미 고른 옷의 어떤 부분을 조정하면 좋은지 알기 어렵습니다.

새로운 스타일을 무한히 추천하기보다 현재 코디에서 최소한의 변경을 돕습니다. 이 문제 정의와 기대 효과는 기획 가설이며, 사용자 조사로 검증된 사실은 아닙니다.

02 / AUDIENCE & SCENARIOS

새 옷보다,
지금 선택에 확신이 필요한 사람.

특정 행사를 앞두고 옷을 고민하며, 복잡한 검색이나 새 구매 없이 현재 선택을 점검하고 싶은 사용자를 대상으로 합니다.

03 / PRODUCT PRINCIPLES

취향은 존중하고,
변경은 작고 구체적으로.

RESPECT PERSONAL STYLE

취향을 출발점으로

선택을 비난하거나 외모를 평가하지 않습니다. 고른 옷을 기준으로 가능한 조합을 살펴봅니다.

CHANGE LESS, IMPROVE MORE

한 가지 변화부터

한 아이템 변경으로 먼저 대안을 찾고, 사용자가 제안을 적용하거나 유지할 수 있게 합니다.

SHOW THE COMBINATION

선택은 즉시 눈앞에

실사 의상 사진을 배치한 코디 보드가 클릭과 동시에 바뀌어 전체 조합을 확인할 수 있습니다.

EXPLAIN THE LIMITS

판단의 한계를 함께

규칙 기반의 참고 의견임을 알리고, 행사·직장의 실제 복장 안내를 우선하도록 안내합니다.

04 / USER JOURNEY

다섯 단계로 완성하는
나만의 코디 보드.

  1. 01상황 선택8가지 장면과
    3가지 꾸밈 정도
  2. 02장소·시간실내·실외, 낮·저녁,
    복장 안내 여부
  3. 03옷 조합5개 카테고리와
    액세서리 다중 선택
  4. 04코디 검토참고 의견 확인,
    적용·유지와 전후 비교
  5. 05보드 저장최종 조합을
    PNG 이미지로 다운로드

사용자는 이전 단계로 돌아가 선택을 조정할 수 있습니다. 같은 탭에서 새로고침해도 편집 상태가 복원되며, 처음 화면으로 돌아가도 선택한 옷을 유지합니다.

05 / CORE FEATURES

선택과 결과가
같은 화면 안에서 이어지도록.

기능현재 구현사용자가 얻는 것
상황·맥락별 시작 조합8개 상황과 3개 꾸밈 정도에 장소·시간·복장 안내를 반영처음부터 옷을 모두 고르지 않아도 되는 시작점
실시간 코디 보드실사 의상·액세서리 사진 40개와 아우터 없음옷의 형태와 색 조합을 한눈에 확인
액세서리 다중 선택가방·시계·주얼리 등을 함께 선택·해제취향에 맞게 디테일 조정
적용 전후 비교명시적으로 적용한 변경만 보드와 저장 결과에 반영미리보기와 최종 결과의 일치
PNG 저장선택한 옷을 브라우저에서 이미지로 구성API 없이 조합을 이미지로 보관
내 옷 사진 등록브라우저에 최대 8개 사진 보관·불러오기·삭제개인 사진 기록. 기본 코디 보드와는 별도 기능

코디 보드는 사람에게 옷을 입힌 가상 피팅 사진이 아닙니다. 선택한 제품 스타일 사진을 배치해 조합을 확인하는 기능입니다.

06 / VISUAL DIRECTION

패션 매거진을 읽듯,
차분하고 편집적인 경험.

아이보리 바탕, 초콜릿 브라운 글자, 얇은 구분선과 넉넉한 여백으로 의상 사진에 시선이 모이도록 구성했습니다. 영문 세리프 제목으로 에디토리얼의 인상을 만들고, 한국어 설명과 구체적인 버튼 이름으로 이용 흐름을 안내합니다.

IVORY / #F4EFE4
CHOCOLATE / #432A23
SAND / #D5C9B8
PAPER / #FCF9F2

PC는 코디 보드와 선택 목록을 나란히 배치합니다. 모바일은 세로 흐름을 유지하면서 ‘코디 보드 보기 / 옷 선택으로 이동’ 버튼으로 긴 스크롤을 보완합니다. 선택 상태는 색뿐 아니라 체크 표시와 접근성 속성으로 전달합니다.

07 / SCOPE & LIMITATIONS

지금 할 수 있는 일과,
앞으로 확장할 일.

AVAILABLE NOW

API 없는 기본 경험

상황 선택, 코디 보드, 규칙 기반 참고 의견, 전후 비교, PNG 저장, 사진 보관은 로그인이나 AI 키 없이 사용할 수 있습니다.

OPTIONAL / NOT ENABLED BY DEFAULT

별도 연결이 필요한 AI

AI 사진 분석·실사 착장 생성 코드는 보관하되 기본 상태에서는 비활성화합니다. 사용할 수 없는 기능을 가능한 것처럼 표시하지 않습니다.

  • 실제 착용 핏이나 개별 의류 제품의 적합성을 보장하지 않습니다.
  • 등록한 개인 사진으로 코디 보드를 구성하는 기능은 아직 제공하지 않습니다.
  • 사진은 해당 브라우저에, 편집 상태는 같은 탭의 세션에 보관합니다. 기기 간 동기화는 없습니다.
  • 코디 조언은 일반적인 복장 기준의 참고 의견입니다. 현장 규정과 공식 안내가 우선입니다.
08 / USABILITY & VALIDATION

기능의 수보다,
선택이 헷갈리지 않게.

소스 코드와 PC·모바일 브라우저 흐름을 점검해 미리보기와 저장 내용의 불일치, 새로고침 시 선택 소실, AI 미지원 기능의 오해, 모바일 이동 불편을 수정했습니다.

  • 적용한 추천만 최종 보드에 반영하고, 적용 즉시 결과를 보여줍니다.
  • 스타일 표기 변경이 사용자의 의상 선택을 바꾸지 않도록 했습니다.
  • 저장 진행 상태와 다운로드 시작을 안내합니다.
  • API가 없는 상태와 연결 실패·시간 초과를 테스트합니다.

현재 검증은 구현 및 브라우저 회귀 테스트 기준입니다. 실제 사용자 인터뷰나 사용성 실험으로 효과를 검증한 단계는 아닙니다. 이후에는 코디 완성률, 단계별 이탈, 추천 적용 이유를 사용자 조사와 함께 확인할 계획입니다.
